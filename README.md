# Запишись

Телеграм-приложение для записи клиентов к специалистам, которые работают сами на себя: тренерам, мастерам, репетиторам. Специалист ведёт расписание и клиентов, клиент записывается в пару касаний, всё внутри Telegram.

**Статус:** рабочий прототип. Развёрнут в облаке и работает круглосуточно, реальных пользователей пока нет.

**Попробовать:** [@ZAPISHISGM_bot](https://t.me/ZAPISHISGM_bot) в Telegram.

## Какую проблему решает

Многие частные специалисты ведут запись вручную: в переписке, в заметках или в голове. Отсюда пропущенные визиты, двойные записи и вечера, потраченные на ответы «а на когда можно?». Большие сервисы онлайн-записи рассчитаны на салоны и для одного человека избыточны.

Здесь ничего не нужно устанавливать: и специалист, и его клиенты уже сидят в Telegram.

## Что умеет

**Для специалиста**

- услуги с ценой и длительностью;
- расписание: разовые и повторяющиеся слоты, закрытие дней, перенос и отмена;
- запись клиента вручную, постоянные клиенты с регулярным временем;
- список клиентов, блокировка, отметка «не пришёл»;
- несколько сотрудников и филиалов;
- рассылка клиентам, промокоды;
- отзывы после визита и статистика по визитам и выручке.

**Для клиента**

- запись по личной ссылке специалиста;
- перенос и отмена своей записи;
- лист ожидания, если нужное время занято;
- напоминания за сутки и за час до визита.

**Подстройка под профессию.** При регистрации специалист пишет своими словами, чем занимается. Приложение подбирает формулировки: у тренера «тренировка» и «клиент», у репетитора «занятие» и «ученик», у врача «приём» и «пациент».

## Модель

Подписка для специалиста, для клиентов бесплатно.

| Тариф | Цена |
|---|---|
| Пробный период | 14 дней бесплатно |
| Соло | 1 490 ₽ в месяц |
| Бизнес | 2 990 ₽ в месяц |

Приём оплаты через ЮKassa написан и включается, когда заданы данные магазина. Без них заявка на оплату уходит администратору в чат.

## Как устроено

- `bot.py`: телеграм-бот. Вход в приложение, уведомления о новых записях и отменах, напоминания по расписанию, резервные копии базы.
- `webapp.py`: сервер приложения. Отдаёт интерфейс и отвечает на запросы из него. Каждый запрос проверяется по подписи Telegram, чтобы никто не мог выдать себя за другого пользователя.
- `db.py`: работа с базой данных SQLite. Тринадцать таблиц: специалисты, слоты, клиенты, услуги, сотрудники, филиалы, отзывы, промокоды, платежи и другие.
- `terminology.py`: подбор формулировок под профессию.
- `miniapp/`: интерфейс приложения, обычные HTML, CSS и JavaScript без фреймворков.

Бот и сервер работают в одном процессе. Всё написано на Python с библиотекой aiogram.

## Как запустить у себя

Нужен Python 3.10 или новее и токен бота от @BotFather.

```
pip install -r requirements.txt
cp .env.example .env        # вписать BOT_TOKEN и TRAINER_ID
python bot.py
```

Чтобы открывалось приложение, а не только чат, нужен публичный https-адрес сервера в переменной `MINI_APP_URL`. Для оплаты добавляются `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY`.
